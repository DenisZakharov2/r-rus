# Документация по игровому процессу (GAMEPLAY)

## Что такое R-RUS

Интерактивный тренажёр по русскому языку для 4 класса. Работает полностью в браузере, без сервера, без установки — достаточно открыть `index.html`.

## Игровой прогресс

* **10 уровней**, в каждом по **5 заданий** (всего 50).
* Следующий уровень открывается только после выполнения всех заданий текущего.
* Задание считается пройденным без ошибки — за такие задания выдаются звёзды ⭐.
* Пройдено всех 50 заданий без ошибок — становится доступна именная **Грамота**.

## Блоки заданий

| Ключ          | Блок                                      |
| ------------- | ----------------------------------------- |
| `syntax`      | Блок 1. Синтаксический разбор предложений |
| `cases`       | Блок 2. Падежи                            |
| `declension`  | Блок 3. Склонения и окончания (-Е / -И)   |
| `conjugation` | Блок 4. Спряжения глаголов                |
| `morphemes`   | Блок 5. Состав слова и орфограммы         |


## Игровая механика

* **Аватар ученика** — 3D-модель (Three.js); можно крутить на 360°, менять плечо питомца.
* **Внутренняя валюта R$** — начисляется за прохождение заданий, тратится в магазине скинов.
* **Скины** — одежда, животные, аксессуары; открываются по мере перехода ученика на следующий уровень.
* **Темы оформления** — классическая, изумрудная, киберпанк.
* **Анкета профиля** — фамилия, имя, школа, класс, пол (показывается в шапке и грамоте).
* **Архив ошибок** — записи о неверных решениях с кнопкой «Отработать» (повтор того же задания).
* **Звук** — можно включить/выключить.
* **Сохранение** — весь прогресс хранится в `localStorage` браузера и остаётся после перезагрузки страницы.

## Технические требования

Браузер с поддержкой WebGL (для 3D-аватара) и подключение к интернету (загрузка библиотек через CDN: Tailwind CSS, Three.js r128, Google Fonts Inter/Rubik).

## Мультиплеер / серверная часть

Отсутствует. Это клиентское приложение, данные не уходят никуда, кроме локального хранилища браузера пользователя.
