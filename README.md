# R-RUS — Интерактивный тренажёр по русскому языку (4 класс)

Клиентская игра-тренажёр по русскому языку для младшей школы (4 класс, ФГОС). Работает полностью в браузере — без сервера, без установки зависимостей и без сборки. Дизайн: стеклянные панели, цветастые акценты, 3D-аватар ученика.

> 🎮 **Автор:** DenisZakharov2 · 📄 **Лицензия:** MIT · 🌐 **Готово к публикации на GitHub Pages**

---

## 📋 О проекте

Ученик выбирает уровень (1–10), проходит 5 заданий на уровне, зарабатывает внутреннюю валюту R$, открывает скины аватара и темы оформления. Прогресс хранится в браузере (`localStorage`) и сохраняется между сессиями. После прохождения всех 50 заданий без ошибок становится доступна именная грамота с данными ученика.

## ⭐ Возможности

* **Система из 10 уровней**, в каждом по 5 заданий (всего 50). Переход на следующий уровень — только после всех заданий текущего.
* **5 блоков заданий:** синтаксический разбор предложений, падежи и окончания, **три склонения** существительных, **спряжение** глаголов, состав слова и орфограммы корня.
* **3D-аватар** (Three.js): поворот на 360°, смена плеча питомца, выбор пола в анкете.
* **Магазин скинов** за внутреннюю валюту R$ (начисляется за задания; внешней монетизации нет).
* **Темы оформления:** классическая, изумрудная, киберпанк.
* **Анкета ученика:** фамилия, имя, школа, класс, пол — отображается в шапке и в грамоте.
* **Грамота за достижения:** доступна только при выполнении всех условий; содержит аватар, фамилию, имя, школу, класс и перечень блоков с количеством заданий без ошибок.
* **Архив ошибок** с кнопкой «Перерешать» — повтор любого ошибочного задания.
* **Звуковые эффекты** с включением/выключением.
* **Адаптивный интерфейс:** десктоп и мобильные устройства.

## 🚀 Быстрый старт

Приложение — один автономный HTML-файл `index.html`. Ничего устанавливать не нужно:

```bash
# склонируйте репозиторий
git clone https://github.com/<ваш-аккаунт>/r-rus.git
cd r-rus

# запустите локально (любым способом, например Python)
python3 -m http.server 8000

# затем откройте в браузере
open http://localhost:8000
```

Или просто откройте файл `index.html` в любом браузере двойным щелчком.

## 🌐 Публикация на GitHub Pages

Проект статический — идеально подходит для бесплатного хостинга на GitHub Pages:

1. Создайте публичный репозиторий на GitHub, например `r-rus`.
2. Загрузите содержимое репозитория (файлы `index.html`, `docs/`, `README.md` и др.) в репозиторий (или привяжите его как удалённый и запушьте).
3. В настройках репозитория → **Pages** укажите источник: ветка `main` (или `master`), папка `/` (root).
4. Дождитесь сборки — сайт будет доступен по адресу `https://<ваш-аккаунт>.github.io/r-rus/`.

Все библиотеки подгружаются по CDN (Tailwind CSS, Three.js, Google Fonts), поэтому для работы достаточно интернет-соединения.

## 🧱 Блоки заданий

| Блок | Код | Что тренирует |
|------|-----|---------------|
| Блок 1 | `syntax` | Синтаксический разбор предложений: цель, интонация, распространённость, основа |
| Блок 2 | `cases` | Падежи и падежные окончания существительных |
| Блок 3 | `declension` | Три склонения (-Е / -И), проверочные слова |
| Блок 4 | `conjugation` | I и II спряжение глаголов, личные окончания |
| Блок 5 | `morphemes` | Состав слова, орфограммы корня |
